# GitHub Guide for Students


## معرفی تمرین
این تمرین با هدف آموزش مفاهیم پایه Git و GitHub به افراد مبتدی تهیه شده است. در این راهنما، دستورات پرکاربرد Git، مدیریت Branchها، ادغام تغییرات، حل Merge Conflict و نحوه همکاری تیمی آموزش داده می‌شود.

## اهداف پروژه
- آشنایی با Git و GitHub
- یادگیری دستورات پایه Git
- مدیریت Branch و Merge
- آشنایی با Pull Request و Code Review
- یادگیری همکاری تیمی در پروژه‌های نرم‌افزاری
